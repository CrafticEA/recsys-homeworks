## 🔴 Часть III. ALS (4 балла)

В ноутбуке ALS был описан теоретически, но не реализован. Теперь реализуйте его.

### Формулы

Модель та же:
$$
\hat r_{u,i} = \mu + b_u + b_i + p_u^\top q_i.
$$

Удобно переписать в матричном виде. Обозначим:
$$
x_u = [b_u;\; p_u;\; 1] \in \mathbb{R}^{L+2},
\qquad
y_i = [1;\; q_i;\; b_i] \in \mathbb{R}^{L+2}.
$$

Тогда $x_u^\top y_i = b_u + p_u^\top q_i + b_i$, и предсказание: $\hat r_{u,i} = \mu + x_u^\top y_i$.

**ALS-шаг для пользователя:**
$$
x_u = \left(\sum_{i \in R(u)} y_i y_i^\top + \lambda I\right)^{-1} \sum_{i \in R(u)} (r_{u,i} - \mu)\, y_i,
$$
где $R(u)$ — фильмы, оценённые пользователем $u$.

**ALS-шаг для объекта:** симметрично, с $x_u$ вместо $y_i$.

## 💡 Советы

**По baseline:**
- Для MovieLens 1M матрица $X$ имеет размер $\sim 1\text{M} \times (1 + 6040 + 3706)$. Используйте `scipy.sparse.lil_matrix` для построения и `tocsr()` для нормальных уравнений.
- `np.linalg.solve` может быть медленным для больших матриц. Для $X^\top X$ размера 9747 × 9747 это ~760 MB, решаемо. Если данных больше — используйте `scipy.sparse.linalg.spsolve`.

**По SVD (SGD):**
- Сохраняйте историю RMSE по эпохам — пригодится для графиков.
- Начинайте с $\gamma = 0.01$, $\lambda = 0.1$, $L = 10$ — это хорошая отправная точка.

**По ALS:**
- Для эффективности предвычислите матрицу $Y^\top Y$ (или $X^\top X$) один раз за итерацию, а не для каждого пользователя.
- При обновлении $x_u$: $A_u = \sum_{i \in R(u)} y_i y_i^\top + \lambda I$. Если $R(u)$ мало, $A_u$ строится быстро.
- Решайте линейную систему `np.linalg.solve(A_u, b_u)` для каждого пользователя.
- Для $L = 20$ каждая ALS-итерация на MovieLens 1M занимает ~5–10 секунд на CPU.

**По сравнению:**
- Замеряйте время **только обучения**, не загрузки данных.
- Для честного сравнения используйте одинаковый train/test split и одинаковое число факторов.
